# Project One Storyboard | Text-Based Adventure Game

## Theme and Storyline

**Theme:**
Sci-Fi Space Station Survival

**Storyline:**
You are an engineer aboard the deep space research vessel *Aegis-9*. A rogie security AI has locked down the ship initiated a self destruct sequence in the Bridge. To shut down the rogue AI and survive, you must navigate the station's decks and gather 6 critical override components before entering the Bridge. If you enter the Bridge without all 6 items, the security AI with eliminate you.

## Rooms

Project One requires a minimum of eight rooms.

1. Airlock Bay
2. Medbay
3. Engineering Deck
4. Crew Quarters
5. Research Lab
6. Armory 
7. Cargo Hold
8. Command Bridge

Add more rooms if your design needs them.

## Items

With the minimum eight-room design, Project One requires at least six items.
Every room except the start room and villain room must contain one item.

1. Bio Scanner
2. Plasma Torch
3. Access Keycard
4. Data Chip
5. EMP Grenade
6. Power Cell

If you add rooms beyond the minimum, add an item for every additional room
except the start room and villain room.

## Villain

 Rogue Security AI (Located in the Command Bridge)
